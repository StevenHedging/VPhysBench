# VPhysBench

Private Hugging Face synchronization mirror for the VPhysBench repository:

https://github.com/StevenHedging/VPhysBench

The active Dataset is `physics_video_seven_scene_v13`, release `13.0.0`.
Five scenes are part of the scored benchmark; `push_bottle` and
`vertical_spring_oscillator` are currently data-only preview scenes.

The Git repository records the exact Hub commit in
`datasets/huggingface.json`. Authentication credentials are stored only in
the user's Hugging Face credential cache and must never be committed here.
